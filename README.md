# 📦 Installation

Install using npm.

```bash
npm install @uxiora/css
```

Using pnpm

```bash
pnpm add @uxiora/css
```

Using Yarn

```bash
yarn add @uxiora/css
```

---

# 🚀 Getting Started

Import the compiled CSS into your project.

```javascript
import "@uxiora/css/dist/uxiora.css";
```

Or include it directly in HTML.

```html
<link rel="stylesheet" href="uxiora.css">
```

# 🏗 Architecture

Uxiora follows a modular architecture.

```
src/

├── foundation/
├── helpers/
├── utilities/
└── uxiora.scss
```

---

# 🎯 Philosophy

Uxiora follows a simple philosophy.

> Build a strong foundation first.

Instead of writing repetitive custom CSS, combine small utility classes to build consistent user interfaces.
